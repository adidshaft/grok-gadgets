# Ready to contribute

Each repository keeps its own contributor queue. These issues need no hardware, account or
sibling checkout. Read the repository's CONTRIBUTING first, then comment on the issue before
you start.

| Repository | Good first issues | Help wanted |
| --- | --- | --- |
| Hub: website, docs, simulator kit | [good first issue](https://github.com/adidshaft/grok-gadgets/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) | [help wanted](https://github.com/adidshaft/grok-gadgets/issues?q=is%3Aissue+is%3Aopen+label%3A%22help+wanted%22) |
| Gateway: MCP tools, simulator, protocol | [good first issue](https://github.com/adidshaft/grok-gadgets-gateway/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) | [help wanted](https://github.com/adidshaft/grok-gadgets-gateway/issues?q=is%3Aissue+is%3Aopen+label%3A%22help+wanted%22) |
| Linux SDK: Python gadgets | [good first issue](https://github.com/adidshaft/grok-gadgets-linux-sdk/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) | [help wanted](https://github.com/adidshaft/grok-gadgets-linux-sdk/issues?q=is%3Aissue+is%3Aopen+label%3A%22help+wanted%22) |
| ESP32 SDK: C++ firmware | [good first issue](https://github.com/adidshaft/grok-gadgets-esp32-sdk/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) | [help wanted](https://github.com/adidshaft/grok-gadgets-esp32-sdk/issues?q=is%3Aissue+is%3Aopen+label%3A%22help+wanted%22) |
| Home Assistant: discovery probe | [good first issue](https://github.com/adidshaft/grok-gadgets-home-assistant/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) | [help wanted](https://github.com/adidshaft/grok-gadgets-home-assistant/issues?q=is%3Aissue+is%3Aopen+label%3A%22help+wanted%22) |

Put the issue's ID (for example `GW-GFI-001`) in your branch name and commits. Each issue lists
its acceptance criteria and the checks to run.

Physical C124 boards, real Linux services, real Home Assistant homes and Windows are separate
opportunities with extra prerequisites; their issues are labelled `needs hardware` or say so.
