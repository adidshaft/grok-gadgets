# esp32-sdk local verification

The evidence is software simulation, transport acceptance and package/build verification, plus one physical kit. On 12 October 2026 the owner's ESP32-S3 + SH1106 OLED kit passed USB and Wi-Fi acceptance, and an approved Grok Bot `rehearse` command showed text on it. Other boards, independent reproduction and native Grok Bot tool calls are not verified.

Follow the component setup guide for local acceptance commands. The component's public repository keeps its versioned verification record under docs/. Machine-specific operational logs and host inventories are excluded from this public site.
