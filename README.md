# Grok Gadgets

Independent, Apache-2.0 gadgets exclusively for the existing Grok Bot. Local alpha under construction; no actual Grok or hardware verification yet.

Five sibling repositories: this project hub, `../grok-gadgets-gateway`, `../grok-gadgets-linux-sdk`, `../grok-gadgets-esp32-sdk`, and `../grok-gadgets-home-assistant`.

The target is M5Stack AtomS3 Lite C124 with a USB-C data cable. Hardware is not available. Simulation, firmware compilation, actual Grok connectivity, and physical observations are separate evidence levels.

Run `python3 scripts/check.py` for hub checks. The complete implementation brief is [here](docs/implementation-plan.md). See [local issues](planning/issues) and [roadmap](planning/milestones.json).
