# Contributing

Start with a labeled ready issue in planning/issues; record your acceptance criteria and owning repository. Create a short-lived branch from main, make a bounded change, run the documented checks, and commit with a local issue ID. Include observed evidence, limitations, dependency changes, and recovery instructions in your review.

Original contributions are Apache-2.0. Keep secrets and private identity mappings outside Git. Documentation and tests count as contributions. Follow [conduct](CODE_OF_CONDUCT.md), [security](SECURITY.md), and [community guidance](community/guidelines.md).

Publication is pending; no public owner or repository URLs have been selected. Local paths are intentional.
