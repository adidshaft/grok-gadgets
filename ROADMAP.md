# Roadmap

The software is an experimental alpha prepared locally; public activation is pending approval. [Canonical stage records](planning/launch-stages.json) and [issue ledger](planning/issues.json) describe current preparation. After activation GitHub Issues/Project become authoritative and local records are generated snapshots.

| Milestone | What closes it |
|---|---|
| Public alpha launch | Approved repositories, hosted checks, reviewed releases, support and Pages verified |
| First independent software setup | Another human follows the published simulator/contributor guide |
| Verified Grok connection | Native invocation receipts or independently retrieved server logs for exact route |
| First physical C124 build | Observed LED/button, disconnect/reconnect and recovery on C124 |
| Real Linux and Home Assistant | Selected real service/peripheral/home paths verified |
| Remote connection and provisioning | Reviewed authenticated HTTPS/OAuth and provisioning implementation |

[Ready contribution queue](docs/contributing/ready-issues.md) · [contribution process](CONTRIBUTING.md) · [planned GitHub Project](publication/project.json). No invented completion percentage, live activity or compatibility claim is used.
