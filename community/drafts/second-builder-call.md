Post it only with the owner's yes, as a pinned GitHub discussion or an update to issue #269.

## Title

Build a gadget for Grok Bot this weekend: be our second builder

## Body

We need one person outside the project to follow our builder guide and tell us where it
breaks.

**What you do (about one afternoon):**

1. Follow [Ship a gadget in one afternoon](https://grokgadgets.org/doc-docs-getting-started-ship-a-gadget).
2. Set up your own relay on a small Linux host, and prepare one or more gadgets: an ESP32-S3
   board or a Linux machine.
3. Hand one gadget to someone with Grok Bot, or use it yourself.
4. Report what happened in [issue #269](https://github.com/adidshaft/grok-gadgets/issues/269):
   each step that worked, each step that did not, and how long it took.

**What you need:** a small Linux host, a domain, Grok Bot, and an ESP32-S3 board with a
part, or a Linux machine. Hardware is your own; the project pays for nothing.

**What we promise:** we answer within a working day, and we fix the guide where it failed
you. Your report goes into the project's verification records under your GitHub name, if you
agree.

**What this is not:** a product, a service or a sale. The project runs no relay for you.
Read [Before you distribute a gadget](https://grokgadgets.org/doc-docs-getting-started-before-you-distribute)
before you give a gadget to anyone.
